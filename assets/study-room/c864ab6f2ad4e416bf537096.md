# CMU115 生物逐題分類覆核
本次範圍只有 CMU115 Q01–Q50。主表共200筆，其餘150筆原欄位保留。入口為[index.html](index.html)，主統計為[report.html](../../biology_chapter_report/report.html)。
- review.json / review.csv：正式逐題資料；primary / secondary 保留真實目錄條目、理由與印刷/PDF頁碼。
- first-pass.tsv / second-review.tsv / second-review.json：兩輪逐題判斷。第二輪是同一執行者的非盲覆核，不宣稱外部第二位審查者。
- first-pass-corrections.json：第二輪發現的來源敘述修正，保留修改前後。
- source-contract.json / question-manifest.json / catalog.json：原卷、答案、釋疑、教材與目錄的雜湊及頁碼；50張完整裁題；真實目錄節點。
- source_pages / questions / textbook_evidence：原卷頁面、單題圖片、被引用教材頁面的可追溯證據。Q30–31各自保留共用背景。
- supplemental-sources.json / research-retrieval.json：課本框架之外的原始研究或官方資料；不宣稱全部出版商全文已取得。
- issue-resolution.json：逐題比較其他可能分類後的證據與結論；原題文字或官方說明差異保留，不以狀態變更取代查證。
- statistics.csv：primary / secondary / both。章級次分類去除主章並去重，同章次條目仍保存在逐題資料。
- baseline.json：可回復備份位置、原檔雜湊及全部 source/Answer 資產的保護清單。
- master-transaction.json：限定50筆合入與修改前後紀錄。信心度0.98是人工分級值，不是經統計校準的正確率；正式狀態另由完整證據及覆核門檻決定。
- qa/：資料、語法、瀏覽器操作、畫面及備份還原演練結果（以實際產出的驗證結果為準）。
本輪未進行其他年度分類、遠端發布、提交或推送。
